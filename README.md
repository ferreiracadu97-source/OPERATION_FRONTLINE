# OPERATION FRONTLINE — Web Prototype 0.1
Protótipo experimental de interface e arena 3D. Usa Three.js por CDN; precisa de internet para carregar a biblioteca.

## Executar no Windows
1. Instale Python 3, se ainda não tiver.
2. Abra a pasta do projeto no Explorador.
3. Na barra de endereço digite `cmd` e pressione Enter.
4. Execute `python -m http.server 8000`.
5. Abra `http://localhost:8000` no navegador.

## Controles
WASD mover • mouse olhar (clique na arena para capturar) • clique disparar • R recarregar • 1–3 trocar arma • H bandagem. No celular há botões direcionais e disparo.

## Já existe
Menu, arsenal de demonstração, categorias de munição e suprimentos, kits/granadas catalogados, configurações visuais, arena 3D simples, movimento local e disparo básico em alvos.

## Ainda não existe
Battle Royale online, bots com IA, zona segura, colisão e gravidade completas, animações finais, física avançada, multiplayer, contas, anti-cheat, mapas completos e gráficos realistas de produção. A seleção de qualidade/FPS ainda é uma interface de protótipo, não um controle completo do renderizador.

Este é um protótipo de validação, não a versão final de lançamento. Sistemas do jogo completo serão implementados gradualmente e depois reavaliados para a versão Unity.
